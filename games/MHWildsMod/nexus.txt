================================================================================
  MH Wilds QOL
================================================================================
In-game QOL menu for Monster Hunter Wilds. Press ~ (tilde).

Hunter cheats, health bars, play speed, smithy crafts, and wallet adds.
Cheats stay off unless you are solo (no other human hunters).
Health bars are overlay only — they are not a cheat and work in a party.
Docked right. Settings tab can rebind the toggle and redock the window.

This zip is REFramework (dinput8.dll), the menu, and ref_cursor.dll.
Unzip into the game folder — next to the exe.

If you already have REFramework, copy the lua file and ref_cursor.dll:

  <game-dir>/reframework/autorun/mhwilds_qol.lua
  <game-dir>/reframework/plugins/ref_cursor.dll


--------------------------------------------------------------------------------
  INSTALLATION
--------------------------------------------------------------------------------

Unzip into the Monster Hunter Wilds install folder (same place as
MonsterHunterWilds.exe).

In Steam: right-click Monster Hunter Wilds → Manage → Browse local files.

  After you extract it will look like this:

    ...\MonsterHunterWilds\dinput8.dll
    ...\MonsterHunterWilds\reframework\autorun\mhwilds_qol.lua
    ...\MonsterHunterWilds\reframework\plugins\ref_cursor.dll

If you already have REFramework, you can keep your dinput8.dll and
copy only the autorun lua and plugins\ref_cursor.dll.

Launch the game, load in, press ~ (tilde).


--------------------------------------------------------------------------------
  USAGE
--------------------------------------------------------------------------------

  ~
      Toggle the menu (change this on Settings → Keybind).
      Look input pauses while the menu is open.
      Function keys are used by the game, so the menu is not F6.

  Health Bars / Move Fast hotkeys
      Unbound by default. Use the Gameplay toggles, or set a hotkey
      on Settings → Keybind if you want one with the menu closed.


--------------------------------------------------------------------------------
  HUNTER
--------------------------------------------------------------------------------

      Toggles and multipliers save to
      reframework\data\refshell_mhwilds.json.

  God Mode
      You take no damage. Health is kept full while this is on.
      Solo only.

  Infinite Stamina
      Stamina does not drain. Solo only.

  Infinite Items
      Pouch use only. Sell, craft, and ammo still consume.
      Solo only.

  Free Craft
      Item recipe list. Missing mats still craft. Materials stay
      in the pouch. Solo only.

  Always Sharp
      Sharpness stays at max. Solo only.

  More Damage
      Scales damage you deal to monsters. Your incoming hits are
      unchanged. Multiplier: 1x / 1.5x / 2x / 3x / 5x / 10x / 99x / 200x.
      Default 2x. Solo only.


--------------------------------------------------------------------------------
  GAMEPLAY
--------------------------------------------------------------------------------

  Health Bars
      World-space bars on large monsters. On by default.
      Name, fill, optional HP text, floating hit numbers, and
      optional distance to you (so you can pick which to chase).
      Crits tick the bar when the hit lands, not after hitstop.
      Small monsters stay off unless you turn them on — packs
      will flood otherwise.
      Draw distance and bar scale are on this tab.
      Not a cheat. Works in a party. Optional hotkey on Settings.

  Move Fast
      Raises play speed (walks, talk, and locked team crawls).
      Multiplier: 1x / 1.5x / 2x / 3x / 5x / 10x. Default 2x.
      Optional hotkey on Settings. Solo only.

  Return to Title
      Gameplay recovery if a post-quest menu never opens.
      Same as pause → Return to Title. Turns Move Fast off first.


--------------------------------------------------------------------------------
  SMITHY
--------------------------------------------------------------------------------

  Free Smithy Crafts
      Weapon tree, hunter armor, Palico sets, and special upgrade.
      Missing mats still forge. Materials and zenny stay.
      Artian and kinsect stay paid. Solo only.

  Unlock All Armor
      Shows every forgeable hunter series. Wilds tabs are Low /
      High rank (MAIN / EX), not Rise Master / Special.
      Reopen the armor list or switch rank tab if a row is missing.
      Solo only.

  Unlock All Palico Armor
      Same for Palico sets. Switch Low / High if a row is missing.
      Solo only.

  Unlock All Weapons
      Reveals hidden names (?????) on nodes already on the tree.
      Does not inject locked story columns. Solo only.


--------------------------------------------------------------------------------
  QUICK ACTIONS
--------------------------------------------------------------------------------

  +10000 Zenny / +999999999 Zenny
      Adds Zenny through the game wallet. HUD may wait until pause.
      Solo only.

  +1000 Pts / +999999999 Pts
      Same for Hunter Points. Solo only.


--------------------------------------------------------------------------------
  SETTINGS
--------------------------------------------------------------------------------

  Window
      Dock Right / Left / Center. Reset Size. Re-docks when you open
      the menu or the game window size changes.

  Keybind
      Rebind the menu toggle (default ~) and optional Health Bars /
      Move Fast hotkeys.


--------------------------------------------------------------------------------
  NOTES
--------------------------------------------------------------------------------

  - Cheats fail closed if the party list cannot be read. The mod is designed to keep
    off while another human hunter is in the session.

  - Health bars are overlay, not a cheat.

  - Move Fast is play speed. More Damage is hits on monsters only.

  - Toggles, hotkeys, and multipliers persist.

  - This is Lua + REFramework. It does not replace game assets.

  - Disable any leftover health_bars.lua in autorun or bars stack.
